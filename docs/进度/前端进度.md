## 3. 最新展示契约

- 上方为当前任务/教材的动态目录树，下方为教材摘要、扫描进度、时间及日志。
- 未取得来源总数的节点显示“暂未获取”，不伪装成 0 题。
- 来源题数、实际唯一题数、题卡出现次数分开；父子目录题数不可直接相加作为教材总题数。
- 扫描 100% 不代表数据无异常；同时显示失败页、重复页、空页、解析和素材异常。
- 以 scanComplete 表示扫描结束，以 dataComplete/completionQuality 表示质量，以 snapshotComplete 和服务端应用状态决定能否应用。
- 当前代码支持抓取窗口结构化数据及日志解析兜底；后续以结构化接口为主，不能靠匹配日志推导业务终态。
- taskId、Collector job UUID、collectorRunId 是不同身份；技术信息可用于排障，不占据主统计区。
