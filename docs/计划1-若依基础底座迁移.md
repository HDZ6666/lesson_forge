# 计划 1：建立纯若依基础底座

> 这是已执行的历史迁移记录。当前目录以根目录 README 和实际代码为准；原 `tools/` 和根 `data/` 已收敛到独立 `collector/` 工程。

## 1. 目标

在当前项目目录中建立一份可以独立启动的若依基础项目，只保留系统底座能力，暂时不实现题库业务。

本阶段只处理：

- Vue 3 + Element Plus 管理端；
- FastAPI + SQLAlchemy + Redis 后端；
- 登录、验证码、用户、角色、菜单、部门、岗位；
- 字典、参数、通知、操作日志、登录日志；
- 在线用户、定时任务、服务监控、缓存监控；
- 基础 SQL、环境变量示例、启动配置和项目文档骨架。

本阶段明确不处理：

- 题库表、题库接口、题库页面；
- Word 导入、题库转换、网站同步；
- 教案生成、规则中心、知识卡、语义模型；
- DOCX 导出；
- 任何题库或教案业务菜单、权限和 ORM。

## 8. 执行顺序

1. 在目标目录执行 `git status --short`，记录用户现有改动。
2. 创建备份记录，确认不覆盖 `docs/word/`、`collector/`、`collector/data/`。
3. 复制源项目管理端和后端源码，不复制依赖安装目录和构建产物。
4. 删除前端业务页面/API/组件，清理动态路由白名单。
5. 删除后端业务包，清理应用注册、模型注册和定时任务示例。
6. 生成只含若依系统表和菜单的基础 SQL。
7. 创建空目录和 `.gitkeep`。
8. 安装管理端依赖并构建。
9. 对后端执行 Python 编译、导入检查和 OpenAPI 启动烟测。
10. 检查全局引用，确保底座没有残留题库/教案路由或模型。
