## 3. 最新展示契约

- 上方为当前任务/教材的动态目录树，下方为“本次任务信息”：状态、扫描进度与依据、章节/知识点/题目统计、时间、错误与运行日志。“当前 N 路窗口”面板已于 2026-09-07 移除（并发路数是运维参数，不再在页面展示）。
- 未取得来源总数的节点显示“暂未获取”，不伪装成 0 题。
- 来源题数、实际唯一题数、题卡出现次数分开；父子目录题数不可直接相加作为教材总题数。
- 扫描 100% 不代表数据无异常；同时显示失败页、重复页、空页、解析和素材异常。
- 以 scanComplete 表示扫描结束，以 dataComplete/completionQuality 表示质量，以 snapshotComplete 和服务端应用状态决定能否应用。
- 进度百分比来自 collector `progressPercent`（页级估算：已扫描页 / 已开始目录已知页 + 未开始目录按层级估算页；未扫描完封顶 99，扫描完成 100），页面用 `attemptedPages / estimatedTotalPages / startedCatalogCount / completedCatalogCount / selectedCatalogCount` 展示依据；旧算法只除以已开始目录并取单目录最高值，会在第一章就到 99% 并停住，已废弃。`utils/sync-task.js` 中的抓取窗口解析函数保留但页面不再使用。
- taskId、Collector job UUID、collectorRunId 是不同身份；技术信息可用于排障，不占据主统计区。

## 4. 待办

2. 核对“扫描完成但不完整”的按钮与提示：可查看异常，不可完整应用；后续可进入补采。
3. 自动恢复界面：开关、下次恢复时间、次数、阻断原因、立即尝试、暂停自动恢复。
4. 自动与手动触发共用后端入口，遇到重复提交、来源冷却或 Collector 离线应显示明确结果。
5. 页面刷新/切换教材后不能显示上一教材的 run、抓取窗口或计数。
6. 将核心交互逐步从源码字符串断言提升到用户行为和接口结果验证；不因测试文件存在就标记已验收。
