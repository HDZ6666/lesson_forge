# 教案生成需求与交互梳理

> 已于 2026-10-01 归档。以下为历史原文，文中的“当前”“唯一入口”“下一步”和完成状态只指当时，不用于指挥本轮实施。接手请读[文档入口](../README.md)；当前需求以[重构实施规格](../重构实施规格.md)为准，进度以[实施任务清单](../实施任务清单.md)为准。

更新时间：2026-10-01。状态：已按用户反馈改为教学内容选题与排版，用户同意按第二版原型制定实现方案，并支持同一内容多组条件；业务代码改造和部署待实施。

老师已经知道本节课要讲什么，系统负责帮助老师筛选、选择、组织对应题目，并在网页编辑后导出 Word。页面和导出内容以题目为主，不展示答案、解析、教师引导、学生活动、教学话术或自动编写的教学过程。

用户已确认两种入口都需要：先列教学内容再配题，以及直接从题库选题后分组排序。两种方式使用同一份教案，能够来回切换；不维护两套结果。

具体落地见[教案选题与编辑实现方案](教案选题与编辑实现方案-2026-10-01.md)，其中区分已确认需求、首版实施默认和后续待明确事项。

## 1 已确认的需求与范围

| 需求 | 当前约定 |
| --- | --- |
| 使用人群 | 自己或少量教师备课 |
| 使用场景 | 新授课、习题或复习课、整理已有材料都需要；最终围绕题目组织 |
| 教师负责的部分 | 确定教学内容、选题条件、题目是否适合学生及使用顺序 |
| 系统负责的部分 | 根据条件筛题，提供候选及数量，支持选题、组题、调整顺序、保存和导出 |
| 第一种入口 | 选择教材与章节或知识点，列出本节教学内容，为每项内容设置条件并配题 |
| 第二种入口 | 直接筛选并浏览题库，逐题选入或按数量选入，可先放入“待整理” |
| 多组条件 | 同一内容或知识点可以配置多组题型、难度与数量条件，例如基础填空 2 题＋提升解答 1 题；每道题只占一个规则名额 |
| 编辑内容 | 教案名称、内容分组、选题条件、题目归属和顺序；题干能否直接修改尚待确认 |
| 展示内容 | 题干及必要图片、表格、公式；编辑页可看筛选所需的题型、难度等信息 |
| 排除内容 | 不展示答案、解析，不生成教师引导、学生活动或教学话术 |
| 使用方式 | 先在网页修改，再导出 Word 备课或打印 |
| 菜单与实施 | 保留一个教案生成模块；业务实现仍在题库基础覆盖之后；当前已整理需求、原型及实现方案 |

不展示答案不等于删除题库已有答案字段或历史数据。对这条选题流程，缺答案不能成为拒绝使用完整题干的理由；题干、公式和必要素材缺失仍需处理。

用户暂未提供真实课例或材料，原型沿用“七年级数学／有理数加法”演示范围，不对应已核实的某版教材页码。整理已有材料继续保留为需求，但文件格式、处理方式和外来题目的保存位置尚待确认。

## 2 常用筛选与高级筛选

筛选要让老师看到实际效果：当前范围、启用条件、符合条件数量、排除本份教案已选题后的可用数量，以及候选题目。常用条件直接可见，高级条件默认收起；不同条件之间按“同时满足”执行。

| 条件 | 建议位置 | 规则 |
| --- | --- | --- |
| 学科、教材 | 备课范围 | 从正式题库选择，记住常用教材；不要求每次重新填写 |
| 章节、小节、知识点 | 常用筛选 | 支持目录选择；正式实现可选多个，默认匹配任一所选知识点，并明确范围 |
| 题型 | 常用筛选 | 选择来源实际具有的题型，可选多个；不能为了够数静默改为不限 |
| 难度 | 常用筛选 | 优先用教师熟悉的分级；高级设置可提供易度区间，说明来源易度系数越大通常越容易 |
| 题数 | 配题操作 | 表示希望选取的数量，不是过滤条件；按整道题计数，小问数另设限制 |
| 年份、近几年 | 高级筛选 | 区分“不限”和明确年份范围；年份未知的题不假装满足限定 |
| 省、市 | 高级筛选 | 来自来源字段，选择省后再列城市；未知地区与“不限”区分 |
| 考试类型 | 高级筛选 | 如单元练习、期中、期末、中考；列表以真实题库字段为准 |
| 最多附带知识点 | 高级筛选 | 限制超出所选范围的已知知识点，不能据缺失标签保证题目绝不涉及其他知识 |
| 最多小问数 | 高级筛选 | 限制整题包含的小问，未知时明确标注，严格模式不当作 0 |
| 图片、表格 | 高级筛选 | 默认允许；老师可排除。无论是否允许，必要素材必须可正常使用 |

“只要本地题”和“优先本地题”不同。第一版先把上述明确条件做成硬筛选；若保留旧版年份、地区、真题偏好评分，应另放“排序偏好”，不得让老师以为已经过滤掉不符合的题。

筛选结果来自实际查询，数量与列表使用同一套条件。目录汇总题量不能代替当前筛选后数量；题目去重后再统计，不把一题多个目录关系算成多题。

## 3 编辑教案的主流程

### 3.1 按教学内容配题

1. 选择教材和本节内容，填写教案名称。
2. 添加教学内容，如“同号相加”“异号相加”“相反数相加”。分组名称可以修改，对应知识点身份独立保存，改名称不改变查询范围。
3. 给每项内容设置题型、难度、题数及其他需要的条件。
4. 查看候选，手动选题或按条件补齐。用户已同意同一内容下支持多组条件，例如基础填空 2 题、提升解答 1 题，界面按需展开；一题即使命中多组也只计入一个名额。
5. 调整题目和教学内容的顺序，预览后导出。

不强制按“导入、例题、练习、拓展、作业”固定模板分组；老师可按知识点、题型或自己的讲授顺序命名。课型仅作为可选方案信息或默认配置，不生成教学文字，也不要求填写学生画像和分钟安排。

### 3.2 直接从题库选题

先设置范围与筛选条件，再看候选。选中的题目可直接放入已有教学内容，也可先进入待整理；之后移动、分组或排序。支持逐题选择和按数量选择，不能因为改筛选条件就清空已选题。

两种入口共用教案 ID、选题集合和排序结果。当前教案已经包含的题目显示“已选入”，不能重复添加；是否以后支持教师有意重复使用同一题另行确认，第一版默认去重。

### 3.3 调整与保留规则

- 补齐只新增当前缺少的题，保留已经选好的题及顺序。
- 调低目标题数不自动删除题目，老师自行移出。
- 调整筛选条件后，已经选入但不满足新条件的题保留并标注，不能宣称全部符合条件。
- 换一题只替换指定位置；没有合适候选时保留原题并说明原因。
- 数量不足显示缺几题，老师可以减少数量、改条件或手动选题，系统不自动放宽知识范围、题型、难度等限制。
- 手动把题目放入其他知识点分组属于明确操作；编辑页显示题目的真实知识点，不能改写原题库归属来迁就分组。
- 从教案移出题目只修改教案，不删除正式题库记录。

多组条件下，每题保存一个明确规则归属，或作为无规则的手选题。手选题、待整理题、不符合新条件但被保留的题，不自动抵扣规则缺额；页面分别显示。删除规则保留题目为手选，删除内容把题目移到待整理。共同配题要避免宽条件抢走窄条件唯一候选，具体算法与计数见实现方案第 4 节。

## 4 页面与导出设计

编辑页顶部是教案名称及教材范围，中间有“按教学内容配题”和“直接从题库选题”两个入口。侧边显示本节内容、已选数量和待整理题目；主区域展示条件及题干，不放教学文字编辑框。

常用操作是添加内容、查看候选、按条件选题、补齐、换题、移出、调整顺序和移动分组。排序必须有明确控件；以后即使增加拖动，也保留可用的上下移动操作。

打印预览默认显示标题、可选分组标题、题号、题干及必要素材。支持题后留白；实现方案首版默认不把来源、难度放进 Word，编辑页仍可查看。取消首版原型中教师版和学生版的拆分，先完成一份不含答案和教学过程的题目文档。

待整理题目不能悄悄漏掉。首版实现沿用原型默认：放在最后作为“补充题”，并在预览外提示；这是可调整的实施默认。Word 与网页使用同一份已保存内容及顺序，题库更新不能静默改写旧教案。

## 6 第一阶段实施与验收建议

建议先完成“筛选 → 候选 → 选入 → 分组排序 → 保存 → Word”闭环，复用现有插件，不增加新服务。复杂材料解析和跨教材组题在明确样例后另行设计。

实施事项已拆为 L01～L08 并同步到项目重构清单；详细数据模型、接口、步骤和验收见[实现方案](教案选题与编辑实现方案-2026-10-01.md)。这些实施项当前全部待完成，下面的勾选项也尚未验收。

验收至少覆盖：

- [ ] 两种入口操作同一份教案，切换不会丢题或重复建结果。
- [ ] 常用和高级条件实际参与筛选，数量与分页列表一致；未知字段不会伪装成符合限定。
- [ ] 年份、地区的筛选与优先排序含义清楚；题目总数按去重后的整题统计。
- [ ] 内容不足只显示缺口，未自动放宽条件。
- [ ] 补齐保留已有题，失败换题保留原题；新条件下不匹配的已选题有标识。
- [ ] 手动选择、移动、移出和排序不修改正式题库；同一教案默认不重复题。
- [ ] 本节内容支持不同题型和难度的组合条件，配题时共同排除已经选过的题。
- [ ] 详情、预览和 Word 不展示答案、解析、教学引导或活动内容。
- [ ] 没有答案但题干完整的题可正常选用；必要素材损坏的题不会作为正常可打印题推荐。
- [ ] 网页保存与导出内容、顺序一致，重新打开草稿可以继续编辑。
- [ ] 使用真实含公式、图片、表格的题验证 Word 编辑与打印效果。

## 7 当前原型与后续确认

第二版交互原型已按上述方向改为题目编辑：可添加教学内容、设置常用及高级条件、查看候选、按数量选入、补齐、换题、移动、排序和预览。所有题目和年份、地区等属性都是演示数据，没有连接正式题库，也没有生成 Word 文件。

2026-10-01 原型交互检查：补齐不覆盖已有题、重复补齐不加重复题、条件不足显示缺口、移出与撤销、顺序调整、高级条件组合筛选、批量选入去重、待整理题目分组及题目版打印预览均通过。此记录仅验证独立原型，不代表正式业务或 Word 文件导出验收。

原型用“基础／提升”演示难度选择；真实难度分级与来源易度区间应在接入正式数据时核定。多知识点选择、同一内容多组条件、市级筛选、真实图片与表格例题、跨页批量选择尚未在原型实现，不把原型视为业务已完成。

后续每轮确认少量具体问题，优先体验筛选是否顺手，再讨论：

1. 是否允许在本份教案中修改题干，还是只选题、换题与排序。
2. 同一知识点的多组条件已确认支持；常用默认组合在真实试用后完善，不作为实现前置。
3. 首版 Word 默认显示可关闭的分组标题、隐藏来源并提供留白设置；试用后确认是否需要来源开关或作业单独导出。
4. 旧材料主要是 Word、PDF 还是粘贴题目，外来题目只用于本份教案还是进入正式题库。

[项目需求与重构清单](项目需求与重构清单-2026-09-30.md)仍是项目范围与实施顺序入口。首版原型的教学设计、答案展示和双版本导出方案已被本次反馈替代，不作为待实现需求继续推进。
