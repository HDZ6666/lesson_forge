`.docx` 单文件可达 100MB 以上（题图、公式图数量大），**不提交 Git**。本地路径：

```text

```

## 2. 文档头

每份有效章节文档开头两段为归档说明，不是目录节点：

```text
北师大版九年级上册数学题库｜第X章 …
全目录、全分页授权归档 · 目录层级 1,2,3
```

导入时应跳过，不要建成知识点。

## 3. 目录层级

标题样式只有两级，路径写在标题文本里，分隔符是全角 ` › `（前后空格 + `›`）。

| 样式 | 文本形态 | 节点含义 |
| --- | --- | --- |
| Heading1 | `第X章 章名` | 章 |
| Heading1 | `第X章 章名 › N 小节名` | 小节 |
| Heading2 | `第X章 章名 › N 小节名 › 知识点名` | 知识点 |

同一份文档里，**小节也用 Heading1**，不要按样式编号推断层级，按 ` › ` 分段数推断：

```text
段数 0 → 章
段数 1 → 小节
段数 2 → 知识点
```

题目挂在最近的知识点（Heading2）下。没有 Heading2 的小节视为尚无知识点，题目仍按最近标题归属。

第四章的目录曾由历史一次性脚本按第六章标题模板写入。该脚本已执行且不在当前工作区；不应对现有 Word 重复运行。

## 4. 题目块

一道题是连续段落，最小形态：

```text
第 1 题  |  ID 34928338  |  原页面第 1 页
25-26八年级下·陕西西安·期末 解答题-应用题 | 容易 (0.85) | 根据概率公式计算概率 列表法或树状图法求概率 名校
1 . 题干……
```

选择题选项各占一段：

```text
A．…
B．…
C．…
D．…
```

题干、小问、表格、图片都在标记段之后、下一题标记之前。页内题号会重置（每页可从 `1 .` 再开始），**稳定主键是外部 ID，不是页内序号**。

### 4.1 标记行

```text
第 {文档序号} 题  |  ID {外部题目ID}  |  原页面第 {页码} 页
```

| 字段 | 规则 |
| --- | --- |
| 文档序号 | 本章从 1 递增的归档序号 |
| 外部题目ID | 组卷网题目 ID，纯数字 |
| 页码 | 来源列表页页码 |

### 4.2 元数据行

紧跟标记行。用 ` | ` 分成三段：

```text
{来源} {题型} | {难度} ({易度系数}) | {标签…}
```

| 段 | 内容 | 解析要点 |
| --- | --- | --- |
| 1 | 来源 + 题型 | 来源在前，题型在后；题型可能带后缀，如 `解答题-应用题`、`解答题-作图题` |
| 2 | 难度 | `容易` / `适中` / `困难`，括号内为 0～1 易度系数 |
| 3 | 标签 | 空白分隔。可能含知识点名、能力标签、`名校`、`真题` 等 |

来源常见形态：

```text
25-26八年级下·陕西西安·期末
2026·江苏无锡·中考真题
2022·山东济宁·模拟预测
21-22八年级下·江苏南通·阶段检测
```

可拆：学年/年份、年级册别、省、市、考试类型。拆不出的整段保留为 `source_descriptor`，不要丢。

### 4.3 题干行

```text
{页内题号} . {题干}
```

题号与点号之间可能有空格。后续段落属于同一题，直到下一条 `第 N 题  |  ID` 或下一条目录标题。

## 5. 导入时必须保留

- 外部题目 ID
- 章 / 小节 / 知识点路径
- 来源原文、题型原文、难度、易度系数、标签原文
- 题干顺序、小问、表格
- 图片和公式图的媒体关系（OOXML `word/media/`）

第一版不要求从 Word 里抽出答案或解析；当前归档也基本不含这两项。

## 6. 与网站同步的关系

`collector/zujuan_sync.cjs` 抓取的是同一套公开题库页面，字段和这里的 Word 归档同源（ID、题型、难度、场景/分类标签）。Word 是离线全量样本；网站同步是可续跑的增量来源。计划 2 的网站题库表按同步契约设计，**不要把 Word 导入表结构直接套到网站同步上**。
