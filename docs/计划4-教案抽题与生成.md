# 计划 4：教案抽题与生成（第一版）

状态：A～E1 已完成并部署（release `20260907-234358`）；E2（真实题库效果）待正式题库有数据后验证，见 §10。创建于 2026-09-07，依据《简化版题库数据库与教案抽题设计方案》与 09-07 讨论定稿的方案。

目标：在已有正式题库（`qb_*` 表）之上，做出一条可用的"选知识点 → 定规则 → 抽题生成 → 预览换题 → 导出 Word"的完整链路，让用户能看到效果并据此提出下一轮需求。

## 1. 边界与硬约束

- 新建独立插件 `lesson`（后端 `service/plugins/lesson`，前端 `pc/plugins/lesson`），不改动 `bank` 插件的表和接口；`lesson` 只读 `qb_*`，只写自己的 `lp_*` 表。
- 题目部分是**确定性抽取**：同一份数据、同一规则、同一 `seed` 结果一致；不用 AI 选题，不自动编答案。
- 文字部分（教学目标、重难点、板书、作业说明）由课型模板 + 知识点名生成初稿，教师可编辑并保存；本版不接 AI。
- 只做 MySQL；沿用插件底座的 `plugin.yaml` 迁移/菜单/权限机制，权限前缀 `lesson:`。
- 新增 Python 依赖 `python-docx`（写入 `service/requirements.txt` 与 `plugin.yaml dependencies.python`）。
- 已知数据事实：目录节点类型 `chapter/section/point`，知识点 = `point`；题型可能带后缀（`解答题-应用题`）；`difficulty_coefficient` 是 0～1 的易度系数（越大越容易）；`answer_html/analysis_html` 目前未采集（`answer_status=not_collected`），导出时明确标注"答案待补充"。
- 正式表当前为空（生产采集中，未应用快照）。开发与验收先用合成数据；真实效果在快照应用后于生产验证。

## 2. 数据模型（迁移 `migrations/mysql/001_init.sql`）

| 表 | 作用 | 关键字段 |
| --- | --- | --- |
| `lp_scheme` | 一次抽题方案（教材、课型、偏好、文字初稿） | `scheme_id`, `scheme_name`, `textbook_id→qb_textbook`, `lesson_type(new/practice/review)`, `duration_minutes`, `recent_years`, `preferred_province`, `preferred_city`, `preferred_exam_types(JSON)`, `prefer_real_exam(Y/N)`, `remark`, 审计列 |

| `lp_generation` | 一次生成结果 | `generation_id`, `scheme_id`, `seed`, `status(ready/partial)`, `rule_snapshot_json`, `summary_json`（每条规则 需要/得到/放宽级别/提示）, `lesson_json`（标题、文字部分、环节顺序）, 审计列 |

不建外键约束（与 `qb_*` 保持一致，靠应用层校验）。

## 3. 抽题引擎（`service/plugins/lesson/service/pick_engine.py`，纯函数可测）

候选获取（每条规则一次查询）：`qb_question_catalog.catalog_id IN rule.catalog_ids` 且 `qb_question.status='0'`，附带该题在本教材内命中的知识点数、素材数、是否含表格。

硬过滤（0 级）：

1. 题型：`question_types` 为空则不限；否则题目 `question_type` 等于列表项或以"列表项-"开头。
2. 易度：`ease_min ≤ difficulty_coefficient ≤ ease_max`；系数为空时按 `difficulty` 文本映射（容易 0.85 / 适中 0.65 / 困难 0.4）。
3. 额外知识点：题目在本教材内关联的 `point` 节点数 − 命中数 ≤ `max_extra_points`。
4. 小问数：`subquestion_count ≤ max_subquestion_count`（为空不限）。
5. `allow_image=N` 时排除有素材的题；`allow_table=N` 时排除 `content_html` 含 `<table` 的题。
6. 同一次生成内 `question_id` 唯一。

放宽（候选不足时逐级放宽，每道题记录选中时的级别）：

- 1 级：易度区间两端各放宽 0.05，`max_extra_points` +1。
- 2 级：题型放宽为大类前缀匹配（`解答题-应用题` → `解答题`），易度再放宽到 ±0.10，`max_extra_points` +2。
- 3 级：忽略题型与易度，只保留知识点、状态、素材/表格限制与唯一性。仍不足则该规则标记 `short`，提示"只能找到 X 题，需要 Y 题"。

排序分（0～100）+ 可复现抖动：

- 年份 30：`year` 在最近 `recent_years` 年内按线性衰减给分，无年份 0 分。
- 地区 30：省匹配 20、市匹配 10；方案未设偏好时统一 15。
- 考试类型 20：在 `preferred_exam_types` 内 20；未设偏好时 10。
- 真题·名校 20：来源文本/试卷名/考试类型含"真题"或"中考" 12 分，含"名校" 8 分。
- 平手项：`provider_asserted` 证据 +1，`assemble_count` 对数 ≤ +1。
- 抖动：`random.Random(seed).uniform(0, 8)`，保证同 seed 同结果，不同 seed 有变化。

换题：同规则、排除本次生成已用题、按同样规则重新取最佳，记录 `replaced_from_question_id`。

## 4. 课型模板（默认规则，前端可改）

| 课型 | 环节与默认题数 / 易度区间 |
| --- | --- |
| 新授课 `new` | 导入 1 题 [0.80,1.00] · 例题 2 题 [0.55,0.85] · 巩固练习 3 题 [0.55,0.90] · 拓展提升 1 题 [0.00,0.55] · 课后作业 4 题 [0.40,1.00] |
| 习题课 `practice` | 例题 2 题 [0.55,0.85] · 巩固练习 4 题 [0.50,0.90] · 拓展提升 2 题 [0.00,0.55] · 课后作业 4 题 [0.40,1.00] |
| 复习课 `review` | 导入 1 题 [0.80,1.00] · 巩固练习 4 题 [0.50,0.90] · 拓展提升 2 题 [0.00,0.55] · 课后作业 5 题 [0.40,1.00] |

多个知识点时，例题/练习环节按知识点各生成一条规则；导入/拓展/作业环节合并为一条覆盖全部知识点的规则。文字初稿模板按课型给出教学目标、重难点、过程说明、板书要点、作业说明，其中以知识点名填充。

## 5. 接口（前缀 `/lesson/plan`，均需登录）

| 方法与路径 | 权限 | 说明 |
| --- | --- | --- |
| `GET /options` | `lesson:plan:list` | 课型、环节、题型与默认模板 |
| `GET /versions`、`GET /textbooks?versionId=`、`GET /catalog-tree?textbookId=` | `lesson:plan:list` | 转发 bank 只读数据，避免页面依赖 bank 权限 |
| `POST /rules/default` | `lesson:plan:list` | 输入课型 + 知识点列表，返回默认规则 |
| `POST /simulate` | `lesson:plan:list` | 输入教材 + 规则列表，返回每条规则 0～3 级候选数 |
| `POST /generate` | `lesson:plan:generate` | 输入方案 + 规则，落库方案与生成结果，返回生成详情 |
| `GET /generation/list` | `lesson:plan:list` | 历史生成分页 |
| `GET /generation/{id}` | `lesson:plan:list` | 生成详情（题目内容、素材、规则汇总） |
| `POST /generation/{id}/regenerate` | `lesson:plan:generate` | 同方案新 seed 生成，返回新生成 |
| `POST /generation/{id}/items/{itemId}/replace` | `lesson:plan:generate` | 换一题 |
| `PUT /generation/{id}/text` | `lesson:plan:generate` | 保存标题与文字部分 |
| `DELETE /generation/{ids}` | `lesson:plan:remove` | 删除生成记录 |
| `GET /generation/{id}/export` | `lesson:plan:export` | 导出 `.docx` |
| `GET /asset/{questionId}/{assetKey}` | `lesson:plan:list` | 题图（转发 bank 素材文件） |

响应统一走 `ResponseUtil`，字段 camelCase。

## 6. 前端（`pc/plugins/lesson/views/plan/index.vue`）

单页三栏：左侧版本/教材选择 + 可勾选目录树（勾选 `point` 节点，父节点勾选等于勾选其下全部知识点）；中间课型与偏好、规则表（题数、题型、易度、额外知识点、图/表开关，可增删行）、"模拟候选"结果；右侧生成结果预览（标题与文字部分可编辑、各环节题目卡片含来源/难度/放宽标记/换一题）、"重新生成""保存文字""导出 Word"，历史抽屉可打开旧生成。菜单：教案生成 → 抽题生成。

## 7. Word 导出

`python-docx` 生成：标题、基本信息表（教材/课题/课型/课时/知识点）、教学目标、重难点、各环节（题号 + 题干；`<img data-asset-key>` 从 `BANK_ASSET_ROOT` 嵌入，缺图写 `[图]`；`<table>` 转 Word 表格；上下标保留）、板书要点、作业说明、附录"题目来源"（年份·地区·试卷）。答案未采集时在附录说明。
