## 4. 当前三端契约

~~~text
PC → Service /bank/sync/* → Collector /v1/jobs
                              ↓
                         SQLite / 原始响应 / 素材
                              ↓
                    按运行 ID 读取不可变快照
                              ↓
            Service 校验、对比、应用 / 离线包发布
                              ↓
                        MySQL 正式题库
~~~

- Collector 不直接写 MySQL；Service 不执行本地采集脚本、不读取 Collector 的 SQLite。
- 同步中心保留 metadata/content 两阶段；独立“同步题库”从当前正式版本/教材选择范围，不要求用户再创建教材同步任务。
- 一个业务任务可包含多本教材；每本教材有独立 Collector run，不能混用 taskId、jobId、runId。
- 新建/重试与断点续采语义不同：重试创建新业务任务；续采保持业务任务身份，新建运行并继承旧快照。后端重启恢复轮询不等于重新执行采集。
- 正式写入有两条实现：任务 apply 服务事务性更新正式表；qbpkg/Publisher 构建影子表并切换。审核通过本身不等于已应用或已发布。
- 100% 表示确定范围完成一轮扫描；失败页、重复页、素材异常单独展示。snapshotComplete=false 的快照不能当作完整替换数据应用。
- 已执行迁移文件不能因格式化或修复而改写历史内容；新增变化使用后续迁移。
